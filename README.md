## Architecture & Engineering Practices

- **Hexagonal Architecture** — ports and adapters for strong domain isolation
- **Vertical Slicing** — feature-first organization for maintainable, readable codebases
- **SOLID Principles & Design Patterns** — applied deliberately, not mechanically
- **REST API Design** — documented with OpenAPI / Swagger
- **Security** — JWT-based auth, roles and permissions, Spring Security configuration
- **Quality** — unit, integration, and component testing; SonarQube analysis; CI/CD pipelines
